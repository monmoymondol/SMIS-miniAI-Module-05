# Module 05 — AI Tools & Mini Project

## 1. Introduction

Artificial Intelligence tools can support software development,
research, writing, learning, and productivity.

In this module, I explored AI assistants and developed SMIS miniAI,
a small application that connects a Python interface to the Gemini API.

## 2. What is an AI Tool?

An AI tool is software that uses artificial intelligence techniques
to assist users with specific tasks.

Examples include:
- ChatGPT
- Google Gemini
- Microsoft Copilot

## 3. Generative AI

Generative AI systems can produce new content from user instructions.

They can generate:
- Text
- Code
- Explanations
- Summaries
- Ideas
- Structured plans

## 4. API Integration

An API allows two software applications to communicate.

In SMIS miniAI:
1. The user enters a prompt.
2. Streamlit receives the input.
3. Python prepares the conversation.
4. The Google Gen AI SDK sends a request.
5. Gemini generates a response.
6. Streamlit displays the response.

## 5. Prompt Engineering

Prompt engineering means writing instructions that guide an
AI model toward a useful response.

SMIS miniAI uses different system instructions for different tasks:
- General assistance
- Programming
- Academic research
- Productivity
- Content writing

## 6. Responsible AI Use

AI-generated information should not automatically be treated as fact.

Important practices:
- Verify technical explanations.
- Check research references independently.
- Do not submit private credentials to AI tools.
- Review generated code before execution.
- Follow academic integrity requirements.

## 7. Conclusion

This project provided practical experience with AI tools,
API integration, Python application development, and
responsible use of generative AI.
