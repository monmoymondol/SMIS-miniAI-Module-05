# Module 05 — Viva Questions and Answers

## 1. What is Artificial Intelligence?
AI is a field of computer science focused on creating systems
that perform tasks requiring human-like intelligence.

## 2. What is Generative AI?
Generative AI creates new content such as text, code, images,
or other outputs from user instructions.

## 3. What is an API?
An API is a defined interface that allows different software
applications to communicate.

## 4. What is the Gemini API?
It is an interface that allows developers to integrate
Google's Gemini models into applications.

## 5. What is Streamlit?
Streamlit is a Python framework for building interactive
web applications, especially data and AI applications.

## 6. What is prompt engineering?
It is the process of designing clear instructions to guide
an AI model toward a desired output.

## 7. What is a system instruction?
A system instruction describes the role, behavior, and
response guidelines for an AI assistant.

## 8. Why does SMIS miniAI have different assistant modes?
Each mode uses different instructions to adapt the assistant
to coding, research, writing, productivity, or general tasks.

## 9. Why should an API key be protected?
An API key grants access to a service. Exposing it can allow
unauthorized use and potentially create costs or quota problems.

## 10. What is the purpose of .gitignore?
It prevents selected files, such as API keys and virtual
environments, from being tracked by Git.

## 11. What is conversation history?
It is the collection of previous messages used to provide
context for later responses.

## 12. What are the limitations of generative AI?
It may produce incorrect facts, incomplete code, biased
responses, or references that do not exist.

## 13. What is the purpose of Streamlit session state?
It stores values across Streamlit reruns within a user's
active session.

## 14. Why is human verification important?
AI outputs can be inaccurate, so a person must review
important information before relying on it.

## 15. What did you learn from this project?
I practiced API integration, prompt engineering, Python,
Streamlit interface development, conversation management,
and secure API key configuration.
