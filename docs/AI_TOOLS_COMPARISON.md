# AI Tools Comparison

## Tools Explored

| Tool | Main area explored |
|---|---|
| ChatGPT | Explanations, coding assistance, brainstorming |
| Google Gemini | AI interaction and Gemini API integration |
| Microsoft Copilot | Coding assistance and productivity workflows |

## Practical Comparison

### ChatGPT
Useful for:
- Understanding programming concepts
- Drafting and improving written content
- Brainstorming project ideas
- Explaining technical topics

### Google Gemini
Useful for:
- Generative AI conversations
- API-based application development
- Prompt experimentation
- Integrating AI into Python applications

### Microsoft Copilot
Useful for:
- Coding support in supported development environments
- Productivity assistance
- Working with supported Microsoft applications

## What I Learned

Different AI tools provide different workflows and integrations.
The best tool depends on the task, available features, access,
and the quality of the output.

For this project, I selected Gemini because the project
demonstrates direct API integration with Python.
